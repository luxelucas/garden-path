# 花園小徑

一個用 three.js 做的 3D 花園探索小遊戲。三分鐘內替花澆水讓它們盛開，再揮網捕捉被花吸引來的昆蟲得分。

## 玩法

- 靠近頭上有水滴的花，按住 **E**／空白鍵澆水，澆到盛開得 10 分；盛開的花不會再枯萎。人物身邊的藍色箭頭會指向最近一朵還沒盛開的花。
- 花一盛開就會吸引昆蟲飛來。面向昆蟲按 **F** 或點一下滑鼠揮網捕捉：
  蜜蜂 5 分、蝴蝶 10 分、瓢蟲 15 分、蜻蜓 20 分、螢火蟲 25 分、金蝶 40 分。
- 5 秒內連續抓到昆蟲會累積連擊，分數最高 ×3。
- 水壺空了就站到池塘邊自動補水。
- 整個花圃盛開 +20，全園盛開 +50，右上角的今日任務每完成一個 +30。
- 撿發光的寶石：青色加 10 秒；彩虹色是「彩虹水壺」，10 秒內澆水快三倍且不耗水。
- 每局中途會下一場陣雨，還沒開的花會自己喝水，雨停後出現彩虹。
- **W A S D** 移動，拖曳畫面轉視角，滾輪縮放。手機上有虛擬搖桿與「澆水」「捕捉」按鈕。

## 執行

單一 HTML 檔，直接用瀏覽器開啟 `index.html` 即可（需要網路以載入 three.js 與字型）。
也可以開啟 GitHub Pages，從 `main` 分支的根目錄發布。
